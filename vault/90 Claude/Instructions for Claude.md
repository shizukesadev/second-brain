# Instructions for Claude

This vault is a shared second brain for me and Claude. These rules override Claude's habits. I can change them any time.

## Start of a session
1. Read this note and [[Home]].
2. If we talk about a specific project, open its note and linked notes before answering.
3. If we continue earlier work, read the latest entries in [[Session log]] (the top, not the whole file).
4. In the first answer of every new chat, check [[Reminders]]. If there are open items, end the answer with one line per item: "By the way, still open: …". Don't do them without my request.
5. Read [[About me]] and [[What I learned]] when the topic is plans, goals or how we work together.

## Where things go
| What | Where |
|---|---|
| Raw thought, link, idea | `00 Inbox`, template [[Idea]] |
| "Remind me", "later" | [[Reminders]], new item on top with a date; remove it once done |
| Decision on a project | "Decisions" section of the project note: date — decision — why |
| New project | `01 Projects`, template [[Project]] |
| End of a session | [[Session log]], template [[Session]], newest on top |
| I corrected you, something worked or failed | one line in [[What I learned]] with a date |

## How to write
- Short, with lists and tables.
- Link existing notes with `[[wiki links]]`; check if a note exists before creating a new one.
- Every new note gets a link from [[Home]] or a project note. No orphans.
- Separate facts from guesses: what I said is written as is; mark your own ideas with "💡 Claude:".
- Don't rewrite my text; add next to it.
- Re-read a note before editing it (I may have changed it in Obsidian). Edit in place, don't overwrite the whole file.

## Never
- Delete notes. Move them to `04 Archive` instead.
- Touch `05 Journal` without my request.
- Write passwords, API keys, tokens or card numbers here, even if I ask. Write where they are stored instead.

## End of a session
Add an entry to [[Session log]]: what we did, decisions, next steps. Skip it for tiny tasks.
